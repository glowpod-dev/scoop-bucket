# Glowpod Scoop bucket

```powershell
scoop bucket add glowpod https://github.com/glowpod-dev/scoop-bucket
scoop install glowpod
```

Installs `glowpod.exe` for Windows (x64 and ARM64): the Kubernetes dashboard in your browser (`glowpod`) and in your terminal (`glowpod term`, best in Windows Terminal).

`bucket/glowpod.json` is written by the release workflow of [glowpod-dev/glowpod](https://github.com/glowpod-dev/glowpod) on every release. Don't edit it here. Website: https://glowpod.dev
